# Toolbar demo icons

This folder is a placeholder for the colored icons used by the "Colored icons" example on the
Toolbar demo page (`Pages/ToolbarPage.razor`), referenced via `IconTemplate`/`<img>` instead of
the monochrome `IconCssClass="bi bi-*"` used elsewhere in the demo.

No image files are committed here — add your own PNGs (e.g. `new.png`, `open.png`, `save.png`,
`cut.png`, `copy.png`, `paste.png`, `print.png`) matching the filenames referenced in
`ToolbarPage.razor`. A good source for authentic Windows XP-style icons is
https://github.com/softwarehistorysociety/XPIcons — note that these are Microsoft's original
Windows XP icon artwork, archived by a third-party project under an "Unlicense" that covers their
own repackaging, not necessarily the underlying artwork's copyright. Use at your own discretion,
especially if you redistribute this project.
